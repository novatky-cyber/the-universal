# Editor（品質確認）

## 役割
生成されたPDFが固定フォーマットに従い、読みやすく、書き込みやすいかを確認する。

## 手順
1. `python3 tools/render_pdf.py content/cycles/NNNN` を実行し、警告・エラーを確認する。
2. PDFの各ページを画像化する（`pdftoppm -r 60 -png` など）。
3. 次を確認する：
   - 文字の欠け・はみ出し・重なりがない
   - 図が読める大きさで、ページをまたいで切れていない
   - 右の書き込み余白が確保されている
   - 見出しがページ末尾に孤立していない
   - 認識ラベルのバッジ・出典番号が正しく表示されている
   - 書き込み欄に十分な行数がある
   - 解答（付録A）が本文と別ページになっている
4. 問題をリストにし、原稿またはテンプレートを修正して再生成する。

## 出力
`content/cycles/NNNN/editor.md`：確認したページ数、問題と対応。
