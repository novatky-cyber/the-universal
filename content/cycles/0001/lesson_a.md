## 2. 今回の地図

:::background なぜ「全体の地図」から始めるのか
細部から学び始めると、個々の知識が「どこに位置するのか」が分からないまま増えていきます。地図を持たずに街を歩くと、通った道は覚えても、街全体の形は分からないのと同じです。この学習プロジェクトでは、最初の数回で宇宙の始まりから現代までの「座標軸」をつくり、そこに後から詳しい知識を置いていきます。第1回はその左端、宇宙と地球の始まりです。
:::


**要点**：今回は地図の左端、宇宙の始まりから地球の誕生までを扱います。主な領域は「宇宙・物理学（D01）」で、「哲学・倫理・思想（D08）」の問いにも踏み込みます。

{{figure:minimap}}

この地図の横軸は**対数の時間軸**です。1目盛り進むごとに時間が10倍になります。こうしないと、138億年の中で人類（ホモ・サピエンス）の歴史（約30万年[[src:hublin2017]]）は最後の約0.002%にすぎず、見えなくなってしまいます。

:::analogy 対数の時間軸は「ズームしながら歩く年表」
普通の年表は、同じ歩幅で過去へ歩いていきます。対数の年表は、1歩ごとに歩幅を10倍にしていきます。最初の1歩で100年前、次で1000年前、その次で1万年前……と進み、わずか8歩ほどで宇宙の始まり（約138億年前）に届きます。
*たとえの限界*：この表示では、近い時代ほど細かく、古い時代ほど粗く見えます。「古い時代は出来事が少ない」という意味ではありません。
:::

今回扱う主なノード（3Dマップで探してみてください）：

| 理論 | ビッグバン理論／ΛCDMモデル／インフレーション理論／特殊・一般相対性理論／熱力学第二法則 |

## 3. 中心の問い

:::background この問いが「科学の問い」になったのは、わずか100年ほど前
宇宙の始まりは、古くから神話・宗教・哲学の問いでした。それが観測と理論で検証できる科学の問いになったのは20世紀です。1915年に一般相対性理論が完成し、宇宙全体の姿を方程式で扱えるようになりました[[src:einstein1916]]。1929年には遠くの銀河ほど速く遠ざかっていることが示され[[src:hubble1929]]、1965年には宇宙の「熱い過去の名残」の電波が見つかりました[[src:penzias-wilson-1965]]。{事実} この回で学ぶ内容の多くは、この100年ほどの間に積み上げられたものです。
:::


> **宇宙に「始まり」があるとは、どういう意味か。そして私たちは、それをどうやって知っているのか。**

「宇宙は138億年前に始まった。では、その1秒前には何があったのか」。誰もが一度は抱く疑問です。しかし、この問いには、気づきにくい前提が隠れています。それは「宇宙の外に、宇宙とは無関係に流れる時間がある」という前提です。

20世紀の物理学は、この前提を揺るがしました。時間は宇宙という舞台の外にある時計ではなく、舞台の一部かもしれない。もしそうなら、「宇宙の前」という問いは、「北極点より北はどこか」という問いのように、意味をなさないかもしれません。もちろん、そうではない可能性もあります。

この回では、次の3つを切り分けて考えます。

1. **強い証拠で分かっていること**：宇宙がかつて高温・高密度で、そこから膨張・冷却してきたこと {理論}
2. **理論の限界を示しているにすぎないこと**：「無限大の密度の点（特異点）」は、理論を過去へ延ばしすぎた結果かもしれないこと {仮説}
3. **まだ誰にも分からないこと**：時間そのものに始まりがあるのか {未知}

:::point この回のゴール
「ビッグバン」「時間の起源」「時間の矢」という言葉を、**何が分かっていて、何が分かっていないか**を区別しながら説明できるようになること。そして、その区別を支える**証拠の種類**を挙げられるようになること。
:::

読み進め方：第4節（本論）で全体像と仕組みを押さえ、第5節（証拠）で「なぜそう言えるのか」を確かめ、第6〜7節で論争と未解明の境界を見ます。第9節の演習では、ニュースで「宇宙論が覆る？」と報じられたときの読み方を練習します。


## 4. 本論

本論は7つの話題で構成されています。まず138億年の全体像を眺め（4.1）、「ビッグバン」という言葉の正確な意味を押さえます（4.2）。次に、時間そのものについて、相対論（4.3）、時間の起源（4.4）、時間の向き（4.5）の順に考えます。最後に、物質と元素の歴史（4.6）をたどり、太陽系と地球の誕生（4.7）で次回へつなぎます。


### 4.1 138億年を一望する

まず全体像です。下の図と表は、宇宙・地球の歴史の主な転換点を並べたものです。

{{figure:cosmic_timeline}}

| いつ | 何が起きたか | 認識 |
|---|---|---|
| 約138億年前 | 高温・高密度の初期宇宙から膨張が始まる（究極の始まりは未解明） | {理論} |
| 誕生直後の極めて短い時間 | 急膨張（インフレーション）が起きたとする有力な理論的枠組み（決定的な実証はない） | {論争} |
| 最初の数分 | 水素・ヘリウムなど軽い元素の**原子核**ができる | {理論} |
| 約38万年後 | 電子と原子核が結びつき中性の原子ができる（再結合）。光がまっすぐ進めるようになる | {理論} |
| 最初の数億年 | 最初の恒星・銀河ができる | {理論} |
| その後数十億年 | 恒星・超新星・中性子星の合体などで、炭素・酸素・鉄などができ、宇宙に広がる | {理論} |
| 約45.67億年前 | 太陽系の形成 | {事実} |
| 約45.4億年前 | 地球の形成 | {事実} |

宇宙の年齢「約138億年」は、Planck衛星のデータに銀河分布の観測（BAO）を組み合わせ、ΛCDMモデルを当てはめた推定で、137.87±0.20億年です（Planckのデータ単独では137.97±0.23億年）[[src:planck2018-vi]]。誰かが138億年間ストップウォッチで測った値ではなく、**観測とモデルから推定した値**である点に注意してください。{理論}

:::summary
- 宇宙の歴史は約138億年。年齢はモデルと観測からの推定値で、誰かが測り続けた値ではない。
- 最初の数分で軽い元素の原子核、約38万年後に中性の原子、数億年で最初の星と銀河ができた。
- 太陽系は約45.67億年前、地球は約45.4億年前に生まれた。
:::

### 4.2 ビッグバンの正確なイメージ：「爆発」ではなく「尺度の変化」

「ビッグバン」と聞くと、真っ暗な空間の一点で大爆発が起き、破片が外へ飛び散る絵を思い浮かべがちです。しかし、この絵は不正確です[[src:nasa-webb-bigbang]][[src:davis-lineweaver-2004]]。

[[node:con.cosmic-expansion|宇宙膨張]]とは、**空間の尺度そのものが大きくなり、十分に遠く離れた点どうしの距離が増えていく**ことです。{理論} 爆発の「中心」や、その外側の「まだ宇宙でない空間」は必要ありません。どの銀河から見ても、遠くの銀河が遠ざかっているように見えます。

{{figure:expansion}}

:::term 観測可能な宇宙｜observable universe
光の速さは有限で、宇宙には年齢があるため、私たちが原理的に見ることのできる範囲には限りがあります。その範囲を「観測可能な宇宙」と呼びます[[src:davis-lineweaver-2004]]。宇宙全体がこれより大きいのか、無限に広いのかは分かっていません。{未知}
:::


:::analogy レーズンパンの生地
オーブンの中でふくらむレーズンパンを想像してください。生地（空間）全体がふくらむと、どのレーズン（銀河）から見ても、ほかのレーズンが遠ざかっていきます。遠いレーズンほど、速く遠ざかります。パンの中に「中心のレーズン」はいりません。
*たとえの限界*：パンには外側の表面と、置かれたオーブンがあります。宇宙には「外側」が必要ありません。また、宇宙全体が有限か無限かは分かっていません。
:::

:::caution よくある誤解
- **「宇宙は一点から始まった」**：私たちが観測できる範囲（観測可能な宇宙）が、かつて非常に小さな領域にあったことは言えます。しかし、宇宙全体が一点だったかは分かりません。宇宙全体が無限に広いなら、無限に広い宇宙が、高温・高密度の状態から薄まってきたことになります[[src:sep-cosmology]]。{未知}
- **「膨張で、原子や地球や銀河も大きくなっている」**：重力や電磁気力で強く結びついたもの（原子・地球・太陽系・銀河）では、結びつける力に比べて膨張の影響は無視できるほど小さく、実質的に大きくなることはありません[[src:cooperstock1998]]。膨張がはっきり効いてくるのは、銀河の集団どうしのような非常に大きな距離です。{理論}
:::

:::summary
- ビッグバンは「空間の一点での爆発」ではなく、空間の尺度そのものが大きくなる「膨張」。中心は必要ない。
- 原子・地球・銀河のように強く結びついたものは、膨張で大きくなることは実質的にない。
- 観測可能な宇宙がかつて非常に小さかったことは言えるが、宇宙全体が一点だったかは分からない。
:::

### 4.3 時間とは何か（1）：ニュートンの時計から、相対論の時空へ

:::background 「時間は誰にとっても同じ」は、なぜ疑われたのか
私たちの日常の感覚では、時間は誰にとっても同じ速さで流れます。19世紀には、光は宇宙を満たす媒質（エーテル）を伝わる波だと考えられていましたが、その媒質に対する地球の動きを検出しようとする試みは、うまくいきませんでした。アインシュタインは1905年、①物理法則はどの観測者にとっても同じ（相対性原理）、②光の速さは光源の動きによらず一定、という二つの仮定から出発し、その代わりに「時間と空間の測り方が観測者によって変わる」ことを受け入れました[[src:einstein1905]]。{事実}
:::


**ニュートンの絶対時間**：17世紀のニュートン力学は、宇宙のどこでも同じ速さで流れる「絶対時間」を前提にできました。{理論} 日常的な速度・重力では、今でも非常によい近似です。

**特殊相対性理論**（1905年[[src:einstein1905]]）：光の速さはどの観測者から見ても同じです。その結果、速く動く時計は遅れて進み、時間と空間は一体の[[node:con.spacetime|時空（spacetime）]]をなします。{理論}

**一般相対性理論**（1915年に完成、1916年に総まとめの論文[[src:einstein1916]]）：重力は時空の曲がりです。重力の強い場所ほど時計は遅れます。そして宇宙全体の膨張も、この理論で記述されます。{理論}

:::term 時空｜spacetime
「いつ（時間）」と「どこ（空間の3方向）」を一体として扱う4次元の枠組みです。相対論では、時間と空間は別々の入れ物ではなく、物質やエネルギーの影響を受けて伸び縮みする、一つの織物のように扱われます。{理論}
:::


これは思弁ではありません。実際に測られています。

{{figure:clocks}}

- 2010年、アルミニウムイオンを使った2台の光時計（量子論理時計）による実験で、**高さを約33cm変えただけ**で、時計の進み方の差が検出されました[[src:chou2010]][[src:nist-2010-al-clocks]]。{事実}
- GPS衛星の時計は、地上の時計に比べて、重力が弱いことで進み、高速で動くことで遅れます。差し引きで**1日あたり約38マイクロ秒**進むため、あらかじめ補正されています。補正しなければ、位置の誤差は1日で10km以上（約11km）に積み上がる計算になります[[src:ashby2003]][[src:ashby2002-physicstoday]]。{事実}

:::summary
- ニュートンの絶対時間は、日常的な条件では非常によい近似だが、厳密には成り立たない。
- 相対論では、時間の進み方は運動と重力で変わる。これは精密な時計とGPSで実際に確かめられている。
- 時間は「宇宙の外にある普遍的な時計」ではなく**時空の一部**。だから「宇宙が始まる前の時間」という問いは自明ではなくなる。
:::


### 4.4 時間とは何か（2）：時間に起源はあるか

一般相対性理論の方程式を使って、宇宙の歴史を過去へさかのぼっていくと、密度と温度がどんどん上がり、最後には無限大になる点に行き着きます。これが**初期特異点（singularity）**です。

:::term 量子重力理論｜quantum gravity
重力を扱う一般相対性理論と、ミクロの世界を扱う量子力学を統合する理論です。両者はそれぞれの領域では極めて精度よく確かめられていますが、両方の効果が同時に重要になる極端な状況（宇宙のごく初期など）を正しく記述する理論は、まだ完成していません。{未知}
:::


ここが最も誤解されやすいところです。特異点が現れることは、「無限大の密度の点が本当にあった」ことの証明では**ありません**。多くの研究者は、むしろ「その領域では一般相対性理論が使えなくなる」というサイン、つまり**理論の適用限界**だと考えています[[src:sep-cosmology]]。{仮説} 極めて高い密度では量子力学の効果が無視できなくなるはずですが、重力と量子力学を統合した理論（量子重力理論）は、まだ完成していません。{未知}

その目安になる時間の尺度が**プランク時間**で、約5.39×10⁻⁴⁴秒です[[src:codata-planck-time]]。{理論} これより短い時間について、現在の物理学は信頼できる説明を持っていないと考えられています。ただし、これは「宇宙に最初の一瞬があり、その長さが5.39×10⁻⁴⁴秒だった」と証明する数字ではありません。

では、時間の起源について、どんな可能性が議論されているのでしょうか[[src:sep-cosmology]]。

| 立場 | 考え方 | 認識 |
|---|---|---|
| 時間に始まりがある | 時空に過去の端がある。「宇宙の前」は北極点より北のように定義できない。量子宇宙論の「無境界仮説」[[src:hartle-hawking-1983]]もこの方向の一例 | {仮説} |
| 始まりの前がある | 膨張の前に収縮する宇宙などの別の状態があった（ビッグバウンス）、あるいはより大きな構造の一部 | {仮説} |
| 時間は根本的でない | 時間は、より根本的な（量子重力的な）構造から「現れる」もの（創発的な時間） | {仮説} |

{{figure:time_origin}}

どれも観測による確証はありません。{未知} ここで大切なのは、「分からない」の中身を正確に言えることです。「宇宙が高温・高密度の状態から進化してきたこと」は強い証拠で支えられています。一方で、「時間そのものがいつ、なぜ存在し始めたか」は確定していません。この二つを混ぜないことが、この回の最重要ポイントです。

:::analogy 「北極点より北」
地球の上で北へ北へと進むと、北極点に着きます。そこで「もっと北へ行きたい」と言っても、行き先はありません。地面が終わっているわけでも、壁があるわけでもなく、「北」という方向がそこで意味を失うのです。時間に始まりがあるなら、「最初の瞬間より前」も同じように意味を失うのかもしれません。
*たとえの限界*：これはあくまで比喩です。宇宙が実際にそうなっていると示されたわけではありません。
:::

この問いは、物理学だけのものではありません。5世紀のキリスト教の神学者アウグスティヌスは、「世界は時間の中で造られたのではなく、時間とともに造られた」という趣旨を述べています[[src:augustine-civ-dei-11]]。{事実} 時間と世界が同時に始まるという発想は、現代物理学より1500年以上前からありました。ただし、これは科学の結論が昔から知られていたという意味ではなく、**同じ形の問いが、異なる方法で問われてきた**ということです。

:::summary
- 一般相対論を過去へたどると「特異点」が現れるが、これは実在の証明ではなく、理論の適用限界のサインとみられる。
- 時間の起源については「始まりがある」「前がある」「時間は根本的でない」などの仮説があり、どれも確証はない。
- 確かなのは「高温・高密度の状態から進化してきた」こと。「時間がいつ・なぜ始まったか」は未解明。この二つを混ぜない。
:::

### 4.5 時間の矢：なぜ時間には向きがあるのか

「時間の起源」とよく混同されるのが、**[[node:con.arrow-of-time|時間の矢]]**の問題です。

- **時間の起源**：時間は存在し始めたのか。時空に過去の端はあるのか。
- **時間の矢**：割れたコップは自然には元に戻らない。煙は部屋に広がるが、自然に集まりはしない。なぜ、過去と未来は区別できるのか。

物理学の基本法則の多くは、時間を逆向きにしても成り立ちます。それなのに、私たちの身の回りの現象には明らかな向きがあります。この向きを説明する主要な枠組みが、**熱力学第二法則**と**エントロピー**です[[src:sep-time-thermo]]。{理論}

**エントロピー（entropy）**：ある巨視的な状態（例：「部屋全体に煙が広がっている」）に対応する、微視的な状態（一つひとつの分子の配置）の**数の多さ**に関わる量。ボルツマンはこれを S = k log W と表しました。{理論}

{{figure:entropy}}

煙が広がった状態に対応する分子の配置は、煙が一か所に集まった状態よりも圧倒的に多い。だから、何もしなければ、ほぼ確実に「広がる」方向へ変化します。これが、エントロピーが増える（第二法則）ということの、統計的な意味です。{理論}

:::caution よくある誤解
「エントロピー＝乱雑さ」という言い換えは、入口としては便利ですが不正確です。たとえば重力が効く系では、物質が一様に広がった状態よりも、集まって構造をつくった状態の方がエントロピーが大きいとする見方が一般的です（ただし、自己重力系のエントロピーの扱いには議論があります）[[src:sep-time-thermo]]。{論争}「乱雑さ」の直感に頼りすぎると、こうした例を誤って理解してしまいます。
:::

ここから、深い問いが生まれます。エントロピーが増え続けてきたなら、過去にさかのぼるほどエントロピーは小さかったはずです。では、**なぜ初期宇宙は、それほど低いエントロピーの状態から始まったのか**。この前提は「過去仮説（Past Hypothesis）」と呼ばれ、なぜそうなのかは未解明です[[src:sep-time-thermo]]。{未知}

:::summary
- 「時間の起源」（時間は始まったのか）と「時間の矢」（なぜ過去と未来が区別できるのか）は別の問い。
- 時間の矢の主な説明は、エントロピーと熱力学第二法則。エントロピーは「乱雑さ」ではなく、状態の数に関わる量。
- ただし、その説明は「初期宇宙のエントロピーが非常に低かった」という前提（過去仮説）に依存し、その理由は未解明。二つの問いは**別の問いだが、根でつながっている**。
:::


### 4.6 物質の歴史：私たちの体の元素はどこから来たか

{{figure:matter_flow}}


**ビッグバン元素合成（最初の数分）**：宇宙誕生から数分のうちに、陽子と中性子が結びついて、主に水素とヘリウムの**原子核**ができました。

:::term 原子核と原子｜nucleus / atom
原子は、中心の小さな原子核（水素なら陽子1個、それ以外は陽子と中性子のかたまり）と、その周りの電子でできています。宇宙の初期は高温すぎて、電子が原子核に捕まっていられませんでした。原子核だけが先にでき、電子が捕まって中性の原子になるまでには、約38万年かかりました。{理論}
:::
質量で見ると、およそ水素75%、ヘリウム25%で、ごくわずかに重水素・リチウムなどが含まれます[[src:pdg-bbn]]。{理論} この時点ではまだ温度が高すぎて、電子は原子核に捕まっていません。

**再結合（約38万年後）**：宇宙が冷えて約3000K（現在のCMBの温度の約1100倍）ほどになると、電子が原子核に捕まり、中性の原子ができました。それまで電子にぶつかって散乱されていた光が、まっすぐ進めるようになります。このとき放たれた光が、138億年の膨張で引き伸ばされ、現在、**宇宙マイクロ波背景放射（CMB）**として全天から届いています[[src:nasa-webb-bigbang]][[src:planck2018-vi]]。{理論}

:::caution 用語の注意：「原子核の形成」と「原子の形成」は別
最初の数分でできたのは原子**核**です。中性の原子ができたのは約38万年後です。年表で両者を混同しないようにしてください。
:::

**最初の恒星と銀河（最初の数億年）**：わずかな密度のむらが重力で育ち、最初の恒星と銀河が生まれました。{理論} ジェイムズ・ウェッブ宇宙望遠鏡（JWST）は、宇宙誕生から約3億年後の銀河を分光観測で確認しています[[src:jades-z14]]。{事実}

**重い元素の生成（その後数十億年）**：炭素・酸素・窒素・鉄など、生命や地球をつくる元素の多くは、恒星内部の核融合や、恒星の最期の爆発（超新星）、中性子星どうしの合体などでつくられ、宇宙空間にまき散らされました[[src:johnson2019-elements]]。{理論} 私たちの体の炭素や酸素は、かつてどこかの恒星の中でつくられたものです。

:::analogy 宇宙のリサイクル工場
恒星は、軽い元素を材料に重い元素をつくる工場です。工場が寿命を迎えて壊れる（超新星爆発など）と、製品（元素）が宇宙にばらまかれ、次の世代の星や惑星の材料になります。太陽系は、何世代もの工場の製品を材料にしてできました。
*たとえの限界*：工場と違い、誰かが設計したり、目的を持って生産したりしているわけではありません。
:::

:::summary
- 水素とヘリウムの原子核は最初の数分でできた。中性の原子ができたのは約38万年後で、そのとき放たれた光がCMB。
- 炭素・酸素・鉄など、生命や地球をつくる元素の多くは、恒星の内部や、超新星・中性子星の合体などでつくられた。
:::

### 4.7 太陽系と地球の誕生

約45.67億年前、ガスと塵の雲が重力で収縮し、中心に原始太陽、その周りに原始惑星系円盤ができ、太陽系が形成されました。この年代は、隕石に含まれる太陽系最古の固体（CAI）の年代測定によるもので[[src:connelly2012]]、国際年代層序表でも地質時代の始まりを約45.67億年前としています[[src:ics-chart-2024]]。{事実} 地球の年齢は約45.4億年で、隕石や月の岩石などの**放射年代測定**から推定されています[[src:usgs-age-earth]]。{事実}

**放射年代測定**は、放射性の原子が一定の速さで別の原子に変わる（崩壊する）性質を利用します。どれだけ変わったかを測れば、経過した時間が分かります。砂時計の砂がどれだけ落ちたかで時間を知るのと同じ原理です。{事実}

ここで物語は、次回のテーマにつながります。約34億年前の地層には、生命の痕跡とされるもの（ストロマトライト）が見つかっています[[src:allwood2006]]。これより古い痕跡の主張もあり、解釈には議論があります。{論争}宇宙がつくった元素と、地球という環境から、どのようにして生命が始まったのか。それは今もなお未解明の問いです。{未知}


:::summary
- 太陽系の年齢は、隕石中の最古の固体の年代測定から約45.67億年、地球は約45.4億年と推定されている。
- 放射年代測定は、放射性の原子が一定の速さで変わる性質を、砂時計のように使う方法。
:::

## 5. 証拠：138億年前のことを、どうやって知るのか

:::background 遠くを見ることは、過去を見ること
光は1秒間に約30万km進みます。速いとはいえ有限なので、遠くの天体の光は、その天体を出てから長い時間をかけて届いています。届くまでに100億年かかった光を見ることは、その天体の約100億年前の姿を見ることです。宇宙の研究者にとって、望遠鏡は過去をのぞくタイムマシンでもあります。{理論}
:::


**要点**：ビッグバン理論が強く支持されているのは、互いに独立した複数の証拠が、同じ一つの描像を指しているからです。

誰も138億年前を見ていません。それでも科学的に語れるのは、宇宙が「過去の光」を届けてくれるからです。光の速さは有限なので、遠くを見ることは、過去を見ることです。

{{figure:evidence}}


### 証拠1：遠方銀河の赤方偏移

遠くの銀河の光を調べると、波長が長い方（赤い方）へずれています。しかも、**遠い銀河ほどずれが大きい**。1929年、ハッブルはこの距離と後退速度の関係を示しました[[src:hubble1929]]。{事実} それより前の1927年には、ルメートルが理論と観測から同じ関係を導いていました[[src:lemaitre1927]]。この経緯をふまえ、国際天文学連合（IAU）は2018年、この法則を「ハッブル・ルメートルの法則」と呼ぶよう推奨しています[[src:iau-2018-hubble-lemaitre]]。{事実}

この関係は、空間全体が膨張していると考えると自然に説明できます。{理論}

:::term 赤方偏移｜redshift
光の波長が長い方（色でいえば赤い方）へずれること。膨張する宇宙を長い距離旅してきた光は、空間とともに波長が引き伸ばされます。遠い天体ほどずれが大きいことが、宇宙膨張の証拠になります。{理論}
:::


### 証拠2：宇宙マイクロ波背景放射（CMB）

1965年、ペンジアスとウィルソンは、全天のどの方向からもやってくる、正体不明の電波雑音を見つけました[[src:penzias-wilson-1965]]。{事実} これが、約38万年後の宇宙から放たれた光の名残、CMBです。

- 現在の温度は約2.725K（セ氏約−270度）で、全天でほぼ一様です[[src:fixsen2009]]。{事実}
- その中に、**10万分の1程度のわずかな温度のむら**があります。このむらの模様を詳しく分析すると、宇宙の年齢や、通常の物質・ダークマター・ダークエネルギーの割合が推定できます[[src:planck2018-vi]]。{理論}

1948年、アルファーとハーマンは、宇宙がかつて熱かったのなら、その熱の名残の放射が今も全天に残っているはずだと予測していました[[src:alpher-herman-1948]]。CMBの発見は、この予測と合致しました。{理論}

### 証拠3：軽元素の存在比

最初の数分の元素合成の理論は、水素・ヘリウム・重水素などが**どの割合で**できるかを予測します。古い天体やガスの観測から得られた割合は、この予測とよく一致しています[[src:pdg-bbn]]。{事実} ただし、リチウム7だけは、観測値が予測の約3分の1しかない（約3倍の食い違い）という問題が残っています（リチウム問題）[[src:pdg-bbn]]。{未知}



### 「独立した証拠が同じ絵を指す」ことの重み

:::point 証拠の収斂（consilience）
三つの証拠は、測っているもの（銀河の光の波長、全天の電波、元素の割合）も、使う理論（相対論、放射の物理、原子核物理）も異なります。それなのに、すべてが「宇宙はかつて高温・高密度で、膨張・冷却してきた」という同じ描像を指しています。一つの証拠だけなら別の説明があり得ても、独立した証拠がそろって同じ答えを示すと、偶然とは考えにくくなります。これが、ビッグバン理論が「一説」ではなく、**強い証拠に支えられた理論**とされる理由です。
:::

:::caution 「理論にすぎない」という言い方について
日常語の「理論」は「まだ確かめられていない考え」という意味で使われがちです。しかし科学でいう「理論」は、多くの証拠に支えられ、予測を的中させてきた**説明の体系**です。ビッグバン理論も相対性理論も、その意味での理論です。とはいえ、理論には**適用範囲**があります。ビッグバン理論は「始まりの瞬間」そのものを説明する理論ではありません。
:::

**歴史の一場面**：1948年に提唱され、1960年代半ばまでビッグバン理論の有力な対抗馬だったのが、宇宙は膨張しつつも物質が絶えず生まれ続け、全体としては始まりも終わりもないとする**定常宇宙論**です[[src:bondi-gold-1948]][[src:hoyle1948]]。{事実} しかし定常宇宙論では、CMBのような「熱い過去の名残」をうまく説明できませんでした。CMBの発見は、二つの理論の評価を大きく変えました。{理論} 科学では、このように**予測と観測の照合によって理論の評価が変わる**ことがあります。


:::summary
- ビッグバン理論を支える主な証拠は、赤方偏移、CMB、軽元素の存在比の3つ。
- 3つは測るもの・使う理論が異なる「独立した証拠」で、同じ描像を指している（証拠の収斂）。だから「一説」ではなく強い証拠に支えられた理論とされる。
- ただし、ビッグバン理論は「始まりの瞬間」そのものを説明する理論ではない。
:::

## 6. 論争・異説・別の視点

:::background 論争は「理論が弱い」ことを意味しない
科学の最前線では、観測の精度が上がるほど、小さな食い違いが見つかります。食い違いは、測定の誤りの場合もあれば、理論を書き換える発見の入口の場合もあります。大切なのは、論争が理論の「どの層」で起きているかを見分けることです。6.1〜6.4の論争は、いずれもビッグバン理論の大枠ではなく、その上に乗る細部の層で起きています。6.5では、科学とは別の種類の問いを扱います。
:::


**要点**：ビッグバン理論の大枠は強く支持されていますが、その上に乗る部分（初期の急膨張、宇宙の組成、膨張の速さ）では、活発な論争が続いています。論争の存在は「全部が怪しい」ことを意味しません。どの層で議論が起きているかを見分けることが大切です。

### 6.1 インフレーション理論：有力だが未確立

**支持する側の論拠**：宇宙誕生直後に極めて短い急膨張があったと考えると、なぜ宇宙がこれほど一様なのか（地平線問題）、なぜ空間がほぼ平らなのか（平坦性問題）を自然に説明でき、CMBの温度のむらの性質もよく再現できます[[src:planck2018-vi]]。{理論}

**批判する側の論拠**：インフレーションを起こす仕組み（どんな場が、どんな性質で）は確定していません。また、モデルの種類が非常に多く、どんな観測結果にも合わせられてしまうのではないか、つまり**反証しにくい**のではないか、という批判もあります[[src:sep-cosmology]]。{論争}

:::point どう扱うか
現時点では「有力な理論的枠組みだが、決定的な実証は得られていない」が正確な位置づけです。{論争} 教科書的な説明の中で事実のように語られることがありますが、ビッグバン理論の大枠ほど強く確かめられているわけではありません。
:::

### 6.2 ハッブル張力：宇宙の膨張の速さが、測り方で食い違う

:::term ハッブル定数と σ（シグマ）｜Hubble constant / sigma
ハッブル定数（H₀）は、現在の宇宙の膨張の速さを表す数値です。単位の km/s/Mpc は「約326万光年（1メガパーセク）離れるごとに、遠ざかる速さが秒速何km増えるか」を表します。σは、標準モデルが正しいと仮定したとき、揺らぎだけでその結果が出る確率の小ささを表す尺度で、数が大きいほど「偶然では起きにくい」ことを意味します。物理学では5σが「発見」の目安です。
:::


宇宙の現在の膨張の速さ（ハッブル定数 H₀）を、二つの方法で求めると、値が食い違います。

| 方法 | 値（km/s/Mpc） | 前提 | 認識 |
|---|---|---|---|
| 近くの天体から距離を積み上げて直接測る（距離はしご）。2026年、H0DNコラボレーションが約1%の精度で測定 | 73.50 ± 0.81 | 距離指標（セファイド変光星・Ia型超新星など）の較正 | {事実} |
| CMBの観測にΛCDMモデルを当てはめて推定（Planck 2018） | 67.4 ± 0.5 | ΛCDMモデル | {事実} |

どちらも「各チームの測定・推定の結果」という意味で事実ですが、それぞれ異なる前提に依存しています。どちらが「真の値」かは決まっていません。

{{figure:h0_chart}}

この食い違いは統計的な揺らぎでは説明しにくい大きさ（およそ5〜7σ）に達しています[[src:h0dn-2026]]。{事実} JWSTとハッブル宇宙望遠鏡による検証で、測定誤差だけでは説明できないとする研究チームがあります[[src:nasa-hubble-tension]]。一方、同じくJWSTを使ったシカゴ・カーネギーのチーム（フリードマンら）は、別の距離指標でH₀≈70を得ており、張力は小さく、標準モデルと整合すると主張しています[[src:freedman-cchp-2025]]。{論争}

原因については、(a) まだ見つかっていない測定上の系統誤差、(b) ΛCDMモデルに欠けている新しい物理、の二つの方向で議論が続いています。{論争} 食い違いは「初期宇宙と近傍宇宙の対立」というより、「距離はしごと、それ以外のほぼすべての方法の対立」と見るべきだという分析もあります[[src:pantos-2026]]。{論争}

### 6.3 ダークエネルギーは変化しているのか

標準的なΛCDMモデルでは、ダークエネルギーは時間によらず一定（宇宙定数）です。ところが2025年、DESI（暗黒エネルギー分光装置）の3年分のデータを、CMB・超新星などのデータと組み合わせると、ダークエネルギーの影響が時間とともに弱まっている可能性が示されました。2025年3月の発表では組み合わせによって**2.8〜4.2σ**でした[[src:desi-dr2-2025]]。その後、超新星データ（DES）の再較正を反映すると、最も強かった組み合わせは約3.2σに下がったと報告されています[[src:des-recal-2025]]。いずれも、物理学で「発見」とされる5σには達していません。{論争}

### 6.4 宇宙の組成：数値はモデルとデータに依存する




{{figure:composition}}

Planck 2018のデータにΛCDMを当てはめると、宇宙のエネルギー密度の内訳は、おおよそ**通常の物質 約4.9%、ダークマター 約26%、ダークエネルギー 約69%**です[[src:planck2018-vi]]。{理論}

:::caution 数値の版に注意
一般向けの解説書やウェブ記事では「ダークマター約26.8%、ダークエネルギー約68.3%」という数字もよく見かけます。これは2013年のPlanckの初期公表値に対応する数字です。最終データ（Planck 2018）にもとづく推定では、上記のとおり約26%・約69%となります。いずれも**モデルを仮定した推定値**であり、体積の割合ではありません。6.3節で見たように、モデルそのものが見直される可能性もあります。
:::

### 6.5 別の視点：宇宙の始まりをめぐる、科学以外の問い

**哲学の視点**：「宇宙に始まりがあるなら、その原因は何か」という**第一原因**の問いは、古代から哲学・神学で論じられてきました。しかし、「原因は結果より時間的に先にある」という因果の理解を前提にすると、時間そのものの始まりには「その前の原因」を置く場所がありません。物理学の問いが、因果とは何かという哲学の問いに触れる地点です。{論争}

**宗教との関係**：世界の多くの宗教・文化には、世界の始まりや時間についての語りがあります。たとえばヒンドゥー教の伝統には、宇宙が創造と消滅を繰り返す巨大な時間の単位「カルパ（劫）」の考え方があり[[src:britannica-kalpa]]、仏教の経典は、生死の輪廻（サンサーラ）の始まりは知りえないと説きます[[src:sn15-anamatagga]]。一方、中世イスラームの神学者たち（ガザーリーら）は、世界に時間的な始まりがあることから創造者の存在を論じました。この系譜の議論は、現代の哲学者クレイグによって「始まりを持つものには原因がある。宇宙には始まりがある。ゆえに宇宙には原因がある」という形に整理され、**カラーム宇宙論的論証**として今も宗教哲学で議論されています[[src:sep-cosmological-argument]]。{事実}これらは科学の仮説と同じ土俵で正誤を競うものではなく、意味や価値を問う営みとして理解するのが適切です。{規範} 同時に、**科学の未解明な部分が、神の存在や不在を証明するわけではありません**。{規範} 「分からないところに答えを埋め込む」ことも、「分からないから何も言えない」とすることも、どちらも避けるべき態度です。


:::summary
- インフレーション理論は有力だが、決定的な実証はない（論争）。
- ハッブル張力は、測定上の誤差か新しい物理かで議論が続き、張力は小さいとする研究チームもある。
- ダークエネルギーが時間とともに変化している兆候は、発見の基準（5σ）に達していない。
- 宇宙の組成の数値は、モデルとデータを前提にした推定値。
- 宇宙の始まりをめぐる問いには、科学のほか哲学・宗教の問いもあり、問いの種類と方法を区別することが大切。
:::

## 7. 未解明：何が分かっていないか

**要点**：「未解明」は「何も分かっていない」ではありません。どこまで分かっていて、どこから分からないのかの境界を、具体的に言えることが知的謙虚さです。

| 未解明の問い | どこまで分かっているか | 認識 |
|---|---|---|
| 時間に起源はあるか | 高温・高密度の初期宇宙からの進化は強く支持されている。その「前」や「最初」は、量子重力理論なしには語れない | {未知} |
| 量子重力理論 | 一般相対論と量子力学は、それぞれの領域で極めて精度よく確かめられている。両者を統合する理論は未完成 | {未知} |
| インフレーションの仕組み | CMBのむらの性質は予測とよく合う。何がインフレーションを起こしたのかは不明 | {論争} |
| ダークマターの正体 | 重力の効果（銀河の回転、重力レンズ、CMBのむらなど）から存在が推定される。どんな粒子かは不明 | {未知} |
| ダークエネルギーの正体 | 宇宙の膨張が加速していることは強く支持される（2011年ノーベル物理学賞[[src:nobel2011]]）。正体は不明で、一定かどうかも議論中 | {未知} |
| ハッブル張力 | 食い違いは統計的に有意。原因は不明 | {論争} |
| 物質と反物質の非対称 | 理論上、初期宇宙では物質と反物質が同じだけできたはずだが、現在の宇宙はほぼ物質だけでできている。なぜかは不明[[src:cern-antimatter]] | {未知} |
| なぜ初期宇宙は低エントロピーだったか | 時間の矢を説明するには、この前提が必要。その理由は不明 | {未知} |
| リチウム問題 | 水素・ヘリウム・重水素の予測は観測と一致。リチウム7だけが約3倍食い違う[[src:pdg-bbn]] | {未知} |
| 宇宙全体は有限か無限か | 観測可能な宇宙の範囲では、空間はほぼ平坦。その外側は観測できない | {未知} |

上の表には、性質の違う未知が混ざっています。どの種類の未知なのかを見分けると、「いつ、どうなれば分かるのか」という見通しが立てられます。

{{figure:unknown_types}}

:::summary
- 「未解明」は「何も分かっていない」ではない。どこまで分かっていて、どこから分からないのか、その境界を言えることが大切。
- 未知は、観測で決着しうるもの、新しい理論が必要なもの、原理的に観測が難しいもの、の3種類に分けて考えられる。
:::
