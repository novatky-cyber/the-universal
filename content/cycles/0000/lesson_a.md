## 3. 中心の問い

> **「世界を理解している」とは、何ができる状態のことか。そして、そこへはどう近づけるのか。**

「世界を理解したい」という願いは、すぐに二つの壁にぶつかります。

一つ目は、**量の壁**です。宇宙論も、進化生物学も、世界史も、経済学も、それぞれの専門家が一生をかけても学びきれない量があります。すべてを知ることは、誰にもできません。

二つ目は、**つながりの壁**です。仮に一つひとつの分野を少しずつ学んでも、それらがバラバラのままでは「世界」は見えてきません。たとえば「なぜ生成AIは2020年代に広がったのか」という問いには、物理学（半導体）、数学（統計と学習）、経済学（投資）、政治（規制）、歴史（過去の技術革新との比較）が、同時にかかわっています。

そこでこのプロジェクトは、目標を「何でも知っている人」には置きません。目標は、

> **未知の問題に出会っても、必要な学問・証拠・検証方法を自分で見つけ、異なる見方を統合し、説明と判断ができる人**

になることです。知識の量ではなく、**地図を持ち、地図を読み、地図を描き直せる力**を目指します。

:::point この問いに、今回どう答えるか
- 「理解している」とは、**説明できる・分析できる・予測を立てて検証できる・自分の誤りを修正できる**ことだと定義します（第4.2節）。
- そこへ近づく方法として、**全体の地図（第4.3〜4.6節）**、**確かさの区別（第5節）**、**考え方の型（後編第9節）**の3つの道具を用意します。
- そして、この3つを「毎週の教材→あなたの説明→評価→次の教材」という循環で回し続けます（第4.2節、後編第10節）。
:::


## 4. 本論

本論は6つの話題で構成されています。まずプロジェクトの目的（4.1）と、鍛える能力・理解の段階（4.2）を確認します。次に、知識を置く「地図」として、10の領域（4.3）、3つの軸と5種類の地図（4.4）、学問ごとの証拠の違い（4.5）を見ます。最後に、その地図の上に、宇宙の始まりから現在までをざっと並べてみます（4.6）。考える道具として、12の分析軸と9つの共通質問（4.7）も紹介します。


### 4.1 目的：世界理解のための「統合知性」

このプロジェクトの目的は、次の一文にまとめられます。

> 宇宙・自然・生命・人間・文明・社会・技術・思想を、互いに関連する一つの世界として捉え、過去から現在に至る変化の構造を理解し、未来について自分の頭で考え、現実の判断・行動へ活かすこと。

仮の名前は「**世界理解のための統合知性の形成**」です。ここでいう「統合」とは、知識を一か所に集めることではなく、**異なる分野の知識を、互いの関係が分かる形でつなぐこと**を指します。

この目的は、まったく新しいものではありません。近い考え方として、少なくとも5つの知的な伝統があります。

| アプローチ | 何をするか | このプロジェクトで借りるもの |
|---|---|---|
| ビッグヒストリー（Big History） | 宇宙の始まりから現在までを、一つの長い時間軸の上で語る[[src:christian2004]][[src:big-history]] | 時間の地図（対数の時間軸） |
| システム思考（Systems Thinking） | 要素そのものより、要素どうしの関係・フィードバック・遅れから全体の振る舞いを考える[[src:meadows2008]][[src:uk-systems]] | 構造・因果の地図、フィードバック |
| 学際研究（Interdisciplinary Studies） | 複数の学問の方法と知見を、一つの問いに向けて組み合わせる | 学問の地図、10領域 |
| 認識論（Epistemology） | 「何を、どんな根拠で知っていると言えるのか」を検討する哲学の分野 | 認識の6分類（第5節） |
| 未来研究（Futures Studies） | 未来を一つの予言ではなく、条件つきの複数の可能性として考える[[src:uk-futures]][[src:unesco-futures]] | シナリオ分析・予測の校正 |

この5つは、主に欧米の学術の系譜から選んだもので、偏りがあります。知識の根拠や世界の全体像を問う思想は他の地域にもあり、Phase 05の哲学史で扱います。

:::term ビッグヒストリー｜Big History
宇宙の誕生から現代までを、自然科学と人文学をまたいで一続きの歴史として扱う学問的・教育的な試みです。歴史学者デヴィッド・クリスチャンが1980年代末から大学で講じ、2004年に教科書『Maps of Time』を出版しました[[src:christian2004]]。のちに教育プログラム「Big History Project」にも発展しています[[src:big-history]]。
:::


:::caution 「統合」は「一つの正解にまとめること」ではない
統合知性は、すべてを一つの理論で説明することを目指しません。たとえば、宇宙の始まりについて物理学が言えることと、哲学や宗教が問うことは、問いの種類が違います（第1回で詳しく扱います）。統合とは、**違う問いを混ぜずに、関係づけること**です。違いを消すのではなく、違いが見える地図をつくります。
:::


:::summary
- 目的は「世界を一つの関連したものとして捉え、変化の構造を理解し、未来を考え、判断に活かす」こと。
- ビッグヒストリー・システム思考・学際研究・認識論・未来研究という5つの伝統から、道具を借りる。
- 統合とは、違う問いを一つにまとめることではなく、違いが見える形で関係づけること。
:::

### 4.2 鍛える6つの能力と、理解の6段階

「世界を理解している」を、測れる形に分解します。このプロジェクトでは、次の**6つの能力**を鍛えます。

| 能力 | できるようになること | 主に鍛える場所 |
|---|---|---|
| 1. 俯瞰力 | 宇宙から現代までを、時間・空間・学問の地図に配置できる | Phase 01、3Dマップ |
| 2. 構造・因果理解 | 関連と因果を区別し、要因の相互作用やフィードバックを説明できる | 思考法（因果推論・フィードバック） |
| 3. 専門的理解 | 必要に応じて、概念・理論・数式・実験・学説の対立まで掘り下げられる | Phase 02以降、深掘りシリーズ |
| 4. 現状分析力 | 政治・経済・技術・社会の現在を、データと歴史から分析できる | 各回の「現在とのつながり」 |
| 5. 未来を考える力 | 条件つきの複数のシナリオと、検証できる予測を立て、結果で更新できる | シナリオ分析・予測の校正 |
| 6. 知的謙虚さ | 自分の無知、理論の限界、異論、価値判断の違いを認め、反証で考えを修正できる | 認識の6分類、「未解明」の節 |

この6つは、それぞれ別の筋肉のようなものです。俯瞰力だけ強くても、専門的理解がなければ「浅く広い」だけになります。専門的理解だけ強くても、俯瞰力がなければ、自分の知識が世界のどこに位置するのか分かりません。

次に、一つひとつの知識について「どこまで分かっているか」を、**6段階**で記録します。

| 段階 | 名前 | 目安 |
|---|---|---|
| L0 | 未確認 | まだ確かめていない |
| L1 | 認知 | 聞いたことがある。用語と大まかな意味が分かる |
| L2 | 説明 | 資料を見ずに、自分の言葉で説明できる |
| L3 | 専門理解 | 根拠となる理論・実証・限界まで説明できる |
| L4 | 統合・応用 | 他の分野とつなげたり、新しい事例に当てはめたりできる |
| L5 | 批判・検証 | 反証や限界を踏まえて、主張の強さを評価できる |

:::caution この段階は、公的な資格の尺度ではない
L0〜L5は、このプロジェクトの学習を管理するための独自の区分です。試験の点数や資格の級とは関係ありません。また、すべての知識をL5にする必要はありません。中心となるテーマ（生成AIなど）は深く、広い周辺は**まずL2**（自分の言葉で説明できる）を目指し、必要になったときに深めます。
:::

段階を上げられるのは、**あなたの回答だけ**です。Claudeが教材を書いても、あなたが読んでも、それだけでは段階は上がりません。教材の第12節（説明課題）と第13節（確認問題）への回答を、Examiner（評価役のClaude）が採点し、その結果だけが理解の記録に反映されます。

:::point 学び方の基本（7つの約束）
1. **全体の地図 ↔ 部分の深掘り**を往復する。どちらか一方に偏らない。
2. 読んで終わりにしない。**資料を閉じて説明する**（閉本説明）。
3. 認識 → 説明 → 専門理解 → 統合・応用 → 批判・検証、という深さを意識する。
4. AIは講師・批判者・問いの生成者・練習相手として使う。**一次資料の代わりにはしない**。
5. 興味や疑問による寄り道は歓迎する。ただし、必ず全体の地図に戻して位置づける。
6. 確かな事実・有力な理論・論争・価値判断・予測を、混ぜない（第5節）。
7. 間違いは記録して直す。間違いを見つけることが、学習の中心である。
:::

:::background なぜ「読む」より「思い出して説明する」のか
学習方法の研究をまとめた総説では、教材を読み返すことや蛍光ペンで線を引くことは、長期的な記憶への効果が比較的小さいと評価されています。一方、**自分で思い出すテスト（練習テスト）**と、**時間をあけて繰り返す学習（分散学習）**は、効果が高いと評価されています[[src:dunlosky2013]]。{理論} 実験でも、同じ時間を使うなら、読み返すより思い出すテストをした方が、1週間後の記憶がよく残ることが示されています[[src:roediger-karpicke2006]]。{事実} このプロジェクトの教材が、毎回「何も見ずに答える」課題で始まり、説明課題で終わるのは、このためです。
:::

**進め方の全体像**：カリキュラムは、この第0回（Phase 00）から始まり、Phase 01（世界の全体地図・8回）→ Phase 02（生成AIの成立条件・5回）→ Phase 03（歴史・経済・政治・哲学・文化への展開・4回）→ Phase 04（現実の問題への応用と未来予測）と進みます。Phase 04のあとは**Phase 05以降の深掘りシリーズ**（たとえば哲学史、進化の単位と「利己的な遺伝子」、宇宙の誕生の最前線）が、あなたの問いと要望をもとに、終わりなく続きます。教材は毎回進み、あなたの回答の評価は、次の教材の冒頭（事前チェック・復習）に反映されます。

:::summary
- 鍛えるのは、俯瞰力・構造因果理解・専門的理解・現状分析力・未来を考える力・知的謙虚さの6つ。
- 理解はL0〜L5の6段階で記録し、段階を上げられるのはあなたの回答の評価だけ。
- 「読む」より「思い出して説明する」方が学習効果が高い。だから毎回、閉本説明の課題がある。
:::

### 4.3 10の領域：生成AIを「入口」にした学問の地図

世界の知識を、まず10の領域に分けます。そして各領域に、**生成AIから入るための問い**を一つずつ置きます。

| 領域 | 主なテーマ | 生成AIからの入口となる問い |
|---|---|---|
| D01 宇宙・物理学 | 宇宙論、量子力学、熱力学、物質、エネルギー | 半導体はなぜ計算でき、計算にはなぜ電力が必要か |
| D02 数学・情報科学 | 論理、統計、確率、情報理論、計算理論 | AIの学習・推論は、数学的にどう成り立つか |
| D03 生命・脳科学 | 進化論、神経科学、認知科学、心理学 | 人間の知能とAIの知能の共通点と相違点は何か |
| D04 技術・産業史 | 農耕、印刷、科学革命、産業革命、電化、コンピューター | AI革命は、過去の技術革新と何が似て、何が異なるか |
| D05 経済・経営学 | 資本主義、労働、企業、金融、イノベーション | AIで生産性・雇用・賃金・企業利益はどうなるか |
| D06 政治・法・国際関係 | 国家、民主主義、権力、法、地政学、国際秩序 | AIを誰が開発・支配・規制するのか |
| D07 歴史・文明・宗教 | 世界史、思想史、社会制度、宗教史、文明間交流 | 知識・技術・制度は、どう蓄積・伝播したか |
| D08 哲学・倫理・思想 | 存在論、認識論、倫理学、科学哲学、政治哲学 | 知能・意識・人間・自由・幸福・責任とは何か |
| D09 文化・文学・芸術 | 美学、芸術史、文学、音楽、メディア | AIが生成できる時代に、創造や真正性の意味は何か |
| D10 社会・未来研究 | 社会学、人口、気候・環境、複雑系、未来予測 | AI社会は、どのような仕組み・格差・機会を生むか |

なぜ生成AIを入口にするのでしょうか。理由は二つあります。一つは、**いま現実に起きている変化**であり、あなたの仕事にも直接かかわるため、学ぶ動機と具体例に事欠かないことです。もう一つは、生成AIという一つの現象を説明しようとすると、**10の領域すべてを通らざるをえない**ことです。生成AIは、世界の地図を一周するための、よい「旅の口実」になります。

:::caution 入口は、物差しではない
入口として生成AIを使いますが、**宗教・芸術・歴史・哲学を「AIの役に立つかどうか」で評価することはしません**。たとえば、中世の宗教思想や古代の詩は、AIと無関係でも、人間と世界を理解するうえで、それ自体の価値があります。生成AIは「入口」であって「物差し」ではありません。
:::

:::analogy 10領域は「大陸」、問いは「港」
10の領域は、世界地図の大陸のようなものです。生成AIからの問いは、それぞれの大陸にある「港」です。港から上陸したら、内陸のどこへ行ってもかまいません。宇宙論の港から上陸して、時間の哲学の山奥へ入っていくこともあります（第1回がまさにそうです）。
*たとえの限界*：実際の学問の境界は、大陸の海岸線ほどはっきりしていません。認知科学のように、複数の大陸にまたがる分野も多くあります。3Dマップでも、一つのノードが複数の領域に属することがあります。
:::

:::summary
- 世界の知識を10の領域に分け、それぞれに生成AIからの「入口の問い」を置く。
- 生成AIを入口にするのは、現実の変化であり、説明しようとすると10領域すべてを通るから。
- ただし、宗教・芸術・歴史などを「AIの役に立つか」で評価しない。入口であって物差しではない。
:::

### 4.4 3つの軸と5種類の地図

同じテーマでも、どの方向から見るかで、見えるものが変わります。このプロジェクトでは、まず**3つの軸**で対象を観察します。

1. **時間**：宇宙・地球・生命 → 人類 → 農耕・文明 → 古代／中世／近世 → 近代 → 20世紀 → 21世紀 → 未来。
2. **空間・スケール**：宇宙、惑星、地域、国家、都市、企業・組織、共同体、個人。日本・米国・中国・欧州・グローバルサウスなどの**地域差**も見ます。
3. **深さ**：先ほどのL1〜L5。

3Dマップは、この3つの軸をそのまま形にしています。**横（長さ）方向が時間**（対数の時間軸）、**円周方向が10の領域**、**中心からの距離が詳しさ**（中心近くが大きなテーマ、外側ほど細かい概念）です。

さらに、どんなテーマにも、次の**5種類の地図**を重ねて見ます。

{{figure:five_maps}}

| 地図 | 問い | 例：「生成AIの普及」なら |
|---|---|---|
| ① 時間の地図 | いつ、何が、どう変化したか | 1956年のダートマス会議[[src:dartmouth-ai]]、2017年のTransformer[[src:vaswani2017]]、2022年の対話型AIの公開[[src:openai-chatgpt]] |
| ② 空間の地図 | どこで、どの地域・規模の問題か | 「注目すべきAIモデル」の開発は米国・中国の機関に集中（2025年は米国59・中国35）[[src:hai-ai-index]]、影響は国・業種で異なる |
| ③ 学問の地図 | 何を、どんな方法・証拠で扱うか | 計算機科学（性能評価）、経済学（生産性の実証）、法学（規制） |
| ④ 構造・因果の地図 | どんな要素・仕組み・相互作用があるか | 計算資源・データ・アルゴリズム・投資・需要の相互作用 |
| ⑤ 認識・限界の地図 | どこが事実で、どこが理論・論争・予測・未知か | 公開時期は事実、雇用への影響は論争中、2035年の姿は予測 |

:::analogy 5種類の地図は「同じ街の、別々の地図」
同じ東京でも、地下鉄の路線図、地形図、ハザードマップ、観光地図、歴史地図では、まったく違う姿が見えます。どれか一枚が「本当の東京」なのではなく、目的に応じて重ねて使います。5種類の地図も同じで、①〜④で対象を描き、⑤で「その地図のどこが、どれくらい確かか」を書き込みます。
*たとえの限界*：街の地図は互いに独立して描けますが、知識の5種類の地図は互いに影響します。たとえば⑤（確かさ）が変われば、④（因果の構造）の描き方も変わります。
:::

:::caution 地図は、現地そのものではない
「地図は現地ではない（The map is not the territory）」という言葉があります。一般意味論の提唱者として知られるポーランド出身の研究者コージブスキーが、1931年の講演で示し、1933年の著書にまとめた考え方です[[src:korzybski1933]]。どんなに精密な地図も、現実を目的に応じて単純化したものです。3Dマップも、このPDFも、あなたの頭の中の地図も同じです。**地図と現実が食い違ったら、直すべきは地図の方**です。
:::

:::summary
- 対象を、時間・空間（スケール）・深さの3軸で観察する。3Dマップの形は、この3軸そのもの。
- どんなテーマにも、時間・空間・学問・構造因果・認識限界の5種類の地図を重ねる。
- どの地図も現実の単純化。食い違ったら、地図の方を直す。
:::

### 4.5 学問ごとに、証拠と方法は違う

「証拠がある」という言葉は、学問によって中身がかなり違います。たとえば、数学の「証明」と、歴史学の「史料による裏づけ」と、経済学の「統計的な推定」は、同じ「証拠」という言葉で呼べても、性質がまったく異なります。

| 学問のまとまり | 方法の例 | 注意すべき点 |
|---|---|---|
| 形式科学（数学・論理学・計算理論） | 証明 | 経験的に測定して確かめる学問とは、確かさの種類が違う |
| 物理・化学・宇宙・地球科学 | 観測、実験、数理モデル、年代測定 | 理論には有効な範囲がある（例：ニュートン力学） |
| 生物・認知・脳科学 | 実験、比較、神経の計測、進化による説明 | 生命の「起源」と「進化」は別の問題として扱う |
| 歴史学・考古学 | 史料批判、遺物、年代測定、解釈 | 現代の価値観を過去に投影しない。残った史料の偏りに注意 |
| 経済学・政治学・社会学 | 統計、因果推論、制度の比較、聞き取り調査 | 相関と因果を区別する。制度や文脈に依存する |
| 哲学・倫理学・宗教研究 | 概念の分析、論証、解釈、歴史・文化の研究 | 「望ましさ」は、観測された事実だけでは決まらない |
| 文学・芸術・美学 | 作品の分析、形式の分析、批評、歴史 | 価値を一つの指標に還元しない |
| 複雑系・未来研究 | シミュレーション、シナリオ、予測の検証 | 「起こりうる未来」と「最も起こりやすい未来」は違う |

この表が意味するのは、**ある学問の物差しで、別の学問を測ってはいけない**ということです。「芸術の価値は、実験で証明されていないから根拠がない」という言い方は、物理学の物差しで芸術を測っています。逆に、「この薬が効くかどうかは、人それぞれの解釈だ」という言い方は、解釈の物差しを、実験で確かめられる問いに当てはめています。

:::term 史料批判｜source criticism
歴史学の基本的な方法です。ある史料（文書・記録など）について、誰が、いつ、何のために書いたのか、写しの過程で変わっていないか、ほかの史料と矛盾しないかを検討し、どこまで信頼できるかを判断します。
:::

:::summary
- 「証拠」の中身は学問によって違う（証明・観測と実験・史料・統計・論証・作品分析など）。
- ある学問の物差しで別の学問を測らない。望ましさは事実だけでは決まらず、効き目は解釈だけでは決まらない。
:::

### 4.6 地図の上に、138億年を並べてみる

ここで一度、時間の地図の上に、宇宙の始まりから現在までをざっと並べてみます。詳しくは第1回〜第6回で一つずつ扱います。今回は「どのあたりに、何があるか」の見当をつけることが目的です。

{{figure:minimap}}

| いつ頃 | 何が起きたか | 認識 | 詳しく扱う回 |
|---|---|---|---|
| 約138億年前 | 高温・高密度の初期宇宙から膨張が始まる[[src:planck2018-vi]] | {理論} | 第1回 |
| 約45.4億年前 | 地球の形成[[src:usgs-age-earth]] | {事実} | 第1回 |
| 約34億年前 | 生命活動の痕跡とされるもの（より古い主張もあり、議論がある）[[src:allwood2006]] | {論争} | 第2回 |
| 約5億3880万年前から | カンブリア紀。動物が多様化する[[src:ics-chart-2024]] | {事実} | 第2回 |
| 約6600万年前 | 白亜紀末の大量絶滅[[src:ics-chart-2024]] | {事実} | 第2回 |
| 約30万年前 | アフリカでホモ・サピエンスが現れる[[src:hublin2017]][[src:smithsonian-human]] | {理論} | 第3回 |
| 約1万2000年前以降 | 複数の地域で、それぞれ農耕・牧畜が始まる[[src:larson2014]] | {理論} | 第3回 |
| 18世紀後半〜19世紀 | 英国で始まる産業革命・工業化（この時代区分自体にも議論がある）[[src:allen2009]] | {理論} | 第5回 |
| 1956年 | 「人工知能（Artificial Intelligence）」の研究分野が形成される[[src:dartmouth-ai]] | {事実} | 第7回 |
| 2017年 | Transformerが提案される[[src:vaswani2017]] | {事実} | 第7回・Phase 02 |
| 2022年11月 | 対話型の生成AIが一般に公開される[[src:openai-chatgpt]] | {事実} | 第7回 |

この表を眺めると、二つのことに気づきます。

一つ目は、**時間の長さの極端な偏り**です。138億年を1年のカレンダーにたとえると、ホモ・サピエンスの約30万年は、大晦日の最後の約11分にすぎません（30万÷138億×365日×24時間×60分≒11.4分）。産業革命以降の約250年は、最後の1秒にも届きません（約0.6秒）。3Dマップや図の横軸が**対数**（1目盛りごとに10倍）になっているのは、このためです。

二つ目は、**歴史は一本道ではない**ということです。この表は、出来事を一列に並べていますが、これは見やすさのための単純化です。

:::caution 歴史を「一本道の進歩物語」にしない（5つの原則）
1. **全体は、部分の足し算だけでは説明しきれない**。要素の相互作用から、新しい性質が現れる（創発）。
2. **歴史は単線的な進歩ではない**。地域差、交流、支配、災害、偶然、後退がある。
3. **時間・場所・規模で、説明は変わる**。
4. **関連と因果を区別する**（後編第9.1節）。
5. **地図は現実そのものではない**（第4.4節）。

たとえば、農耕は世界の複数の地域で、それぞれ独立に、異なる時期に始まりました[[src:larson2014]]。{理論} 狩猟採集から農耕への移行は一様ではなく、農耕を始めれば必ず国家ができる、というわけでもないという議論があります[[src:scott2017]]。{論争} また、「古代→中世→近代」という三つの区分は、ヨーロッパの歴史叙述から生まれたものです[[src:goody2006]]。{事実} この区分を世界の他の地域にどこまで当てはめてよいかには、強い批判があります[[src:goody2006]]。{論争} 文字の有無で文明の優劣を決めないことは、このプロジェクトの立場です。{規範}
:::

:::point 産業革命は「蒸気機関のおかげ」か
よくある説明に「蒸気機関が発明されたから産業革命が起きた」というものがあります。しかし歴史研究では、**複数の要因の組み合わせ**が議論されており、どれを重く見るかで立場が分かれます。{論争} たとえば、高い賃金と安い石炭が機械化を割に合うものにしたとする説[[src:allen2009]]、知識・文化（啓蒙）・制度の役割を重く見る説[[src:mokyr2009]]、中国の先進地域と比べて、石炭の立地や新大陸の資源（植民地）が英国の分岐を生んだとする説[[src:pomeranz2000]]があります。 一つの原因に単純化しないことは、このプロジェクトの品質基準の一つです。第5回で詳しく扱います。
:::

:::summary
- 宇宙の約138億年の中で、人類の歴史はごく最後の一瞬。だから時間軸は対数で描く。
- 年表は見やすさのための単純化。歴史は一本道の進歩ではなく、地域差・交流・偶然・後退を含む。
- 大きな出来事を一つの原因に単純化しない。
:::

### 4.7 考えるための道具箱：12の分析軸と9つの共通質問

地図の上に出来事を置いたら、次は「なぜそうなったのか」「これからどうなるのか」を考えます。そのとき、見落としを減らすためのチェックリストが二つあります。

**世界を動かす12の分析軸**

| # | 軸 | 例 |
|---|---|---|
| 1 | 物質・資源 | 鉱物、食料、水、土地、半導体の材料 |
| 2 | エネルギー | 太陽光、石炭・石油、電力、原子力 |
| 3 | 自然環境 | 気候、地形、地震、感染症、生態系 |
| 4 | 人口 | 人口規模、出生、高齢化、移動 |
| 5 | 技術・知識 | 科学、機械、通信、医療、AI |
| 6 | 生産・経済 | 労働、資本、貿易、価格、金融 |
| 7 | 政治・権力 | 国家、戦争、外交、政策、統治 |
| 8 | 法・制度 | 所有権、契約、企業法、国際法 |
| 9 | 文化・思想 | 宗教、教育、規範、価値観、芸術 |
| 10 | 社会関係 | 家族、階級、ジェンダー、組織 |
| 11 | 情報・メディア | 文字、印刷、報道、インターネット |
| 12 | 偶然・危機・選択 | 疫病、災害、発見、戦争、指導者の選択 |

これは「世界を動かす12の法則」ではありません。**分析の取りこぼしを減らすためのチェックリスト**です。たとえば生成AIの普及を考えるとき、技術（5）と経済（6）だけを見がちですが、エネルギー（2：データセンターの電力）、法・制度（8：著作権や規制）、偶然・選択（12：特定の企業や研究者の判断）も効いています。また、軸どうしの影響は一方向ではなく、互いに戻り合います（フィードバック、後編第9.4節）。

**どのテーマにも使う9つの共通質問**

| # | 質問 | 中身 |
|---|---|---|
| 1 | 何か | 定義、範囲、似た概念との違い |
| 2 | いつ・どこか | 時間、場所、スケール |
| 3 | なぜか | 原因、背景、必要条件と十分条件、別の説明 |
| 4 | どう機能するか | 仕組み、工程、構成要素 |
| 5 | 誰に関係するか | 主体、権限、利益・損失・責任 |
| 6 | 何につながるか | 波及、フィードバック、二次的な影響 |
| 7 | どう知るか | 一次的な証拠、測定、検証、競合する理論 |
| 8 | 何が分からないか | 誤差、仮説、研究上の空白 |
| 9 | 今後どうなりうるか | 条件つきのシナリオと、予測の検証 |

:::term 必要条件と十分条件｜necessary and sufficient conditions
「AがなければBは起きない」とき、AはBの**必要条件**です。「Aがあれば必ずBが起きる」とき、AはBの**十分条件**です。たとえば、酸素は火が燃えるための必要条件ですが、酸素があるだけで火がつくわけではないので、十分条件ではありません。歴史の説明では、「必要だった条件」と「それだけで十分だった条件」を混同しやすいので注意します。
:::

12の分析軸と9つの共通質問を支えるのが、いくつかの**共通の概念**です。構造、システム、メカニズム、因果関係、フィードバック、創発、経路依存性、インセンティブ（人や組織を動かす誘因）、制約条件、トレードオフ（あちらを立てればこちらが立たない関係）、反実仮想、不確実性。これらは日常語としても使われますが、学術的な意味は少し狭く、厳密です。後編で、このうちいくつかを思考法として練習します。

:::summary
- 12の分析軸は「法則」ではなく、見落としを減らすチェックリスト。軸どうしは互いに影響し合う。
- 9つの共通質問（何か・いつどこ・なぜ・どう機能・誰に・何につながる・どう知る・何が分からない・今後）を、どのテーマにも当てる。
:::


## 5. 証拠：「知っている」の確かさを区別する

このプロジェクトのすべての教材と3Dマップのノードには、**認識ラベル**が付いています。これは、その主張が「どの種類の知識で、どれくらい確かか」を示す札です。第0回で最も大切な道具の一つです。

| ラベル | 意味 | 例 |
|---|---|---|
| {事実} 観測された事実 | 資料・実験・測定で確認できる | 地球の年齢は約45.4億年（放射年代測定）[[src:usgs-age-earth]] |
| {理論} 強い証拠に支えられた理論・説明 | 確立度は高いが、適用できる範囲と限界がある | 自然選択による進化、ビッグバン理論 |
| {論争} 解釈・論争 | 複数の学説が競合している | 産業革命の主な原因、インフレーション理論 |
| {規範} 規範的判断 | 正しさ・望ましさ・価値の問題 | 「AIの開発は規制すべきか」 |
| {仮説} 予測・仮説 | 条件つきの将来や、まだ検証されていない説明 | 「2035年に業務の多くが自動化される」 |
| {未知} 未知・未解明 | 現時点で、科学的・歴史的に確定できない | 時間そのものの起源、生命が誕生した仕組み |

事前チェックの問1に戻ってみましょう。B（地球の年齢）は観測された事実に近く、A（10年後の仕事）は予測、C（民主主義の望ましさ）は規範的判断、D（産業革命の原因を一つに絞る）は論争中の問題を単純化したものです。4つとも「〜である」という同じ形の文ですが、**中身の種類がまったく違います**。

:::analogy 認識ラベルは「食品の表示ラベル」
スーパーの食品には、原材料・産地・消費期限が書かれています。中身を食べなくても、それがどんなものか、どれくらい信用できるかの見当がつきます。認識ラベルも同じで、主張の中身を詳しく調べる前に、「これは測定された事実か、有力な理論か、意見が分かれている話か、価値の話か、予測か」の見当をつけさせてくれます。
*たとえの限界*：食品表示は法律で決められた基準に従いますが、認識ラベルは、出典と研究の現状をもとにClaudeが付け、独立した検証役（Verifier）が確かめたものです。研究が進めばラベルは変わりえますし、境界線上の判断もあります。
:::

確かさの区別では、二つの極端な誤りを避けます。

- **「科学的に未解明なら、何も分からない」**という誤り。たとえば、時間の起源は未解明ですが、宇宙がかつて高温・高密度だったことは、独立した複数の証拠で強く支えられています[[src:planck2018-vi]]。{理論}未解明な部分があることは、すべてが不明であることを意味しません。
- **「専門家の意見が分かれているなら、どの説も同じくらい正しい」**という誤り。論争中でも、証拠の強さには差があります。このプロジェクトでは、未確定の問題でも、**すべての説を同等には扱いません**。

:::caution 価値判断は、事実から自動的には出てこない
「AIで生産性が20%上がった（事実だとする）」から、「だからAIの導入を進めるべきだ」{規範} とは、すぐには言えません。「べきだ」と言うためには、雇用への影響、分配、リスクなど、**何を大切にするか**という価値の前提が必要です。「〜である」から「〜すべきだ」は直接には導けないという考えは、18世紀の哲学者ヒュームにさかのぼるとされ、ヒュームの一節の読み方や、この考えがどこまで成り立つかには議論があります[[src:sep-hume-moral]]。{論争} それでも、事実と価値判断を区別しておくと、議論のどこで意見が分かれているのかが、はっきり見えます。
:::

教材の中では、この6つの区別を、本文中の小さな札（{事実}{理論}{論争}{規範}{仮説}{未知}）で示します。札が付いていない文は、多くの場合、説明のための言い換えやたとえです。

:::summary
- すべての主張に、事実・理論・論争・規範・仮説・未知のラベルを付けて区別する。
- 「未解明なら何も分からない」も、「意見が割れているならどれも同じ」も誤り。証拠の強さを比べる。
- 「べきだ」は事実だけからは出てこない。価値の前提を明示する。
:::


## 6. 論争・異説・別の視点

このプロジェクトの方法そのものにも、異なる見方や批判がありえます。主要な論点を4つ挙げ、それぞれ最も強い反論を添えます。

### 6.1 広く学ぶか、深く学ぶか

**論点**：世界全体を広く学ぶことは、どの分野でも素人のままに終わる「浅く広く」にならないか。{論争}

- **広さを重視する立場**：現代の大きな問題（気候、AI、パンデミック）は複数の分野にまたがるため、分野をつなぐ力が欠かせない。システム思考も、要素だけでなく関係を見ることの重要性を強調する[[src:meadows2008]]。
- **最も強い反論**：分野をつなぐには、つなぐ先の分野を正確に理解している必要がある。浅い理解どうしをつなぐと、もっともらしいが間違った「物語」が生まれやすい。
- **このプロジェクトの対応**：全体地図と深掘りを**往復**し（第4.2節の約束1）、中心テーマ（生成AI）と、あなたの関心のあるテーマ（Phase 05以降）は深く掘る。広い周辺はまずL2（説明）を目標にする。

### 6.2 「大きな歴史」は一つの物語を押しつけないか

**論点**：宇宙から現代までを一本の時間軸で語ると、すべてが現在（あるいは人類）に向かって進んできたかのような「目的論的な物語」になりやすい。{論争}

- 時間軸を一本にすること自体は、比較のための道具である。しかし、その上に「進歩」の矢印を描くかどうかは、別の判断である。
- **このプロジェクトの対応**：第4.6節の5原則（一本道にしない、地域差・偶然・後退を含める）を品質基準とし、各回で「別の地域・別の立場からの見方」を入れる。時代区分の相対性も明示する（[[node:con.periodization|時代区分の相対性]]）。

### 6.3 生成AIを入口にすることの利点と危うさ

**論点**：生成AIを入口にすると、学ぶ内容が「現在の技術にとって役に立つかどうか」に偏らないか。{規範}

- **利点**：現実の変化に結びつくため、学ぶ動機と具体例がある。一つの現象から10の領域を一周できる。
- **危うさ**：古代の宗教や芸術が、「AIとの関係」でしか語られなくなるおそれがある。また、AIの話題は変化が速く、数年で古くなる。
- **このプロジェクトの対応**：「入口であって物差しではない」という原則を品質基準に入れる（第4.3節）。最新の数値は、教材を作るたびに一次情報で再確認する。

### 6.4 AIに教わることの限界

**論点**：AIが作った教材で学ぶことは、信頼できるか。{論争}

- 生成AIは、もっともらしいが誤った説明や、実在しない文献を作ることがある[[src:walters-wilder2023]]。{事実}
- **このプロジェクトの対応**：①すべての主張に出典を付け、②作成者とは別の検証役（Verifier）が出典と主張を照合し、③実在を確認できない文献は根拠として使わない。それでも誤りは残りうるため、教材の第11節（用語）・付録B（出典）から原典に当たれるようにしている。AIは**入口と練習相手**であり、一次資料の代わりではない（第4.2節の約束4）。

:::summary
- 広さと深さは対立しうる。全体と深掘りを往復することで両立をめざす。
- 一本の時間軸は比較の道具であって、進歩の物語ではない。
- 生成AIは入口として便利だが、物差しにしない。AIの教材は出典と独立検証で裏づける。
:::


## 7. 未解明：何が分かっていないか

このプロジェクトの方法についても、まだ分かっていないこと、確かめながら進めることがあります。

:::caution 正直に言えば、まだ分からないこと
- **「理解」をどこまで正確に測れるか**：L0〜L5は、説明・応用・批判の課題で測りますが、文章の回答から理解の深さを判定することには限界があります。評価の精度は、回を重ねて検証していきます。{未知}
- **ある分野で身につけた考え方が、別の分野でどこまで使えるか**：たとえば、予測の訓練によって、訓練した種類の問題では成績が上がったと報告されています[[src:tetlock-gardner2015]]。{事実} しかし、それが別の分野の判断にどこまで移るかは、まだよく分かっていません。{未知}
- **地図の見えていない部分**：3Dマップは、引き継ぎ資料の範囲から始まっています。まだ地図に載っていない重要な分野や、地域の偏りがあるはずです。新しい教材と、あなたの問いによって、少しずつ埋めていきます。{未知}
:::

これらは、プロジェクトを止める理由ではありません。むしろ、知的謙虚さ（6つ目の能力）を、自分たちの方法にも当てはめるということです。分からないことを明示し、分かったら直します。
