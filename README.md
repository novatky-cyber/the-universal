# The Universal

An intellectual production model for understanding this universe.

宇宙・自然・生命・人間・文明・政治・経済・技術・思想・文化・芸術を、相互につながった一つの地図として学ぶための、個人用の知的生産システム。生成AIを入口に、地図を自律的に更新し、学習教材と変更点レポートをPDFで届ける。

- **3Dマップ**：`index.html`（GitHub Pages）
- **学習教材**：`output/lessons/`
- **変更点レポート**：`output/reports/`
- **設計書**：`docs/`（要件定義書から読む）
- **開発・運用ルール**：`CLAUDE.md`

このリポジトリはClaudeが設計書と `CLAUDE.md` のルールに従って開発・運用している。
