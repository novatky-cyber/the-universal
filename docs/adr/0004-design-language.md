# ADR-0004 デザイン言語：モノクロの線画＋赤のアクセント、英語のナビゲーション

- 日付：2026-11-23／状態：採用（確認②のユーザー指示による）

## 背景
試作版（v0.1.0）は、虹色の理解度、光る立体、角丸のパネルなど、定型的な「AIが作った感じ」の見た目だった。ユーザーから、参考画像（黒地に白い線のネットワーク図、ワイヤーフレームの層構造と赤のグラデーション）の方向性、書体へのこだわり、英語のメニュー＋日本語のコンテンツ、凡例はメニューから、メモ欄は不要、という指示を受けた。

## 決定
| 要素 | 決定 |
|---|---|
| 色 | 地：ほぼ黒（ビューア）／紙の白（PDF本文）。線：白（ビューア）・墨（PDF）の細線。アクセントは朱赤 `#c8402a` のみ |
| 理解レベルの色 | 虹色をやめ、生成り→朱赤の一方向のグラデーション（弱い→強い）。L0は灰 |
| ノードの形 | 光る立体をやめ、ワイヤーフレームの多面体（種類で形を変える） |
| 線 | すべての関係を極細・低不透明度で常に描き、密度で構造を見せる。選択時に関係線だけ白く浮かび上がらせる |
| 時間の層 | 時間軸の目盛りごとにワイヤーフレームの輪（円筒）／枠（展開）を描き、層構造として見せる |
| 書体 | 欧文ディスプレイ：Instrument Serif／欧文ラベル・メニュー：IBM Plex Mono／和文見出し：Shippori Mincho B1／和文本文：Zen Kaku Gothic New |
| ナビゲーション | 英語（MENU, INDEX, LESSONS …）。コンテンツは日本語 |
| PDF | 表紙は黒地の線画（地図のネットワーク）。本文は白地、ハイラインの表、色で塗らない囲み（左罫＋英字ラベル） |

## 理由
- 色数を絞ると、強調（朱赤）と構造（線の密度）が際立ち、情報の階層が見やすくなる。
- 理解レベルを一方向のグラデーションにすると「濃いほど理解が深い」と直感的に読める。
- 英語のナビゲーションは短く、デザイン上の統一感を出しやすい。学習内容は母語の日本語で読む方が理解しやすい。

## 影響
- ビューアの書体は Google Fonts から読み込む（オフラインでは代替書体になる）。
- PDFの書体は npm の @fontsource から取得して `.cache/fonts` に置く（`tools/setup_fonts.sh`）。取得できない環境では Noto CJK で代替し、レポートに記載する。
