# ADR-0005 書体の統一、白黒のテーマ、2D表示

- 日付：2026-11-24／状態：採用（ユーザーの指示による。ADR-0004 の書体・色の決定を一部置き換える）

## 背景
v0.2 では欧文2書体（Instrument Serif／IBM Plex Mono）と和文2書体（Shippori Mincho B1／Zen Kaku Gothic New）を使い分けていた。ユーザーから「英語・日本語ともに書体が混在して見える。統一してほしい」「ベースは白と黒で、テーマで変わるように」「PDFは白地の標準（ライト）」「2Dでも見られるように」との指示を受けた。

## 決定
1. 欧文は IBM Plex Mono、和文は Zen Kaku Gothic New の各1書体に統一する。混在して見える原因だった「欧文用の要素の中の和文が端末の標準書体になる」問題は、書体の指定順に和文書体を続けて書くことで解消する。
2. ビューアにライト／ダークのテーマを設ける（既定は端末の設定に従う）。
3. PDFは表紙を含めて白地に統一する。
4. 2D（平面）表示を追加する。

## 理由
- 書体の種類を減らし、太さ・大きさ・字間で階層をつくる方が、統一感が出る。等幅の欧文はデータアートの参照画像の雰囲気と合い、数値や記号も揃う。
- Zen Kaku Gothic New は見出しから本文まで1書体で読みやすく、PDFでの学習にも向く。
- 白地は印刷・書き込み・長時間の学習に向き、黒地は没入感がある。利用者が選べるようにする。
- 2Dは全体の位置関係を一目で把握しやすく、3Dの「奥が見えない」問題を補う。

## 影響
- Instrument Serif と Shippori Mincho B1 は使わない（setup_fonts.sh は残すが、読み込むのは2書体のみ）。
- 3Dのマテリアルの色をテーマに応じて差し替える処理が必要になる。
