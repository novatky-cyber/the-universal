# ADR-0002 ビューアは静的HTML＋three.js、円筒座標＋展開表示

- 日付：2026-11-23／状態：採用

## 背景
要件F4は「時間×領域（円周）×詳細度」の座標型3D地図を求める。iPhoneのSafariで動き、費用0円であること。

## 選択肢
1. 静的HTML＋three.js（CDN）、座標は計算で固定
2. 力学モデルのネットワーク描画ライブラリ（3d-force-graph 等）
3. ビルド工程のあるフレームワーク（React等）

## 決定
1を採用。円筒表示を既定とし、円筒の裏側が見えにくい問題を補うため「展開表示」への切替を加える（要件の範囲内の補助機能）。

## 理由
- 力学モデルは配置が毎回変わり、「地図」としての位置の記憶が育たない。座標を固定すると、同じ知識が常に同じ場所にあり、頭の中の地図と対応させやすい。
- ビルド工程がないため、将来のセッションが修正しやすく壊れにくい。

## 影響
three.js をCDNから読み込むため、オフラインでは表示できない（要件上、旅先オフライン利用は不要）。
