# ADR-0001 知識グラフをJSONでGitに置く

- 日付：2026-11-23／状態：採用

## 背景
知識・理解・変更履歴を長期間、無料で、追跡可能に管理する必要がある。各実行は記憶のない新しいセッションで始まる。

## 選択肢
1. JSON＋JSON Schema をGitで管理
2. Notion データベース
3. ホスティングされたDB（Supabase 等）

## 決定
1を採用。

## 理由
- Gitの履歴がそのまま変更履歴になり、差分（map_diff）を機械的に作れる。
- 無料・外部サービスへの依存なし。GitHub Pages のビューアから直接読める。
- Notionは既存資産の参照元としては有用だが、厳密なスキーマ検証と差分集計に向かない。

## 影響
ノード数が数千を超えたら、ファイルを領域ごとに分割する（その時点でADRを追加）。
