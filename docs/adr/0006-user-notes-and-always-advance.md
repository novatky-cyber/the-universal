# ADR-0006 あなたのメモの取り込み、第0回の新設、常に進む進行

- 日付：2026-11-24／状態：採用（ユーザーの指示による。要件定義書 v1.3）

## 背景
ユーザーから次の指示を受けた。①教材がChatGPTでの対話の続きのように読めるので、ChatGPT分も含めて第1回から作り直してほしい。②復習を続ける設定はなくし、どんどん進めてほしい（回答は週末にまとめて行う）。③NotionのAI用語集・用語集の内容もこの地図にまとめたい。「このモデルは私の知識や知恵を含む世界の知識や学問を総合的にプロットして可視化したもの」だから。

## 決定
1. **第0回（P00-S01、L0000）を新設**する。ChatGPTでの最初の対話で扱った土台（目的・6能力・理解の段階・10領域・3軸と5種類の地図・学問ごとの証拠・認識の6分類・12の分析軸・9つの共通質問・8つの思考法・7ステップ）を、独立した教材にまとめる。L0001 からChatGPTへの言及を除き、単独で読める正式版にする。
2. **常に次のセッションへ進む**（DOC-04 v1.2 §4）。回答の評価は、次以降の教材の第1節（事前チェック・復習）に反映する。P04 の後は P05（深掘りシリーズ）を、ユーザーの要望から終わりなく続ける。
3. **あなたのメモを地図に置く**：Notionの3つの用語集の用語を、type `term`・`origin: user-note` のノードとして取り込む（DOC-03 §1.3）。写すのは名前と1〜2文の定義だけで、正本はNotionのまま（読むだけ）。Claude由来の知識とは、形（小さな六角形）・メニュー（GLOSSARY）・出典の種別（`user-note`）で区別する。
4. 用語の定義は Verifier が1サイクル約10件ずつ確かめ、誤りや古さは**ノードを直さず**変更点レポートで指摘する。

## 理由
- 第0回を独立させると、以前の対話を見返さなくてもプロジェクト全体が分かる。方法の教材を宇宙の教材と分けることで、どちらも標準のページ数に収まる。
- 回答を待たずに進めると、ユーザーの学習のリズム（週末にまとめて回答）に合う。理解の浅い部分は、復習と後続の教材で補える。
- ユーザー自身の知識を同じ座標に置くと、「自分の知識が世界の知識のどこにあるか」が見える。一方で、ユーザーのメモをClaudeが書き換えると、どちらが正本か分からなくなる。だから写しと指摘に限る。

## 影響
- 公開リポジトリのため、顧客の業種・居住地・個人的な行動を推測させうるページは取り込まない。除外は題名のハッシュで指定し、公開ファイルに題名を残さない（`tools/migrations/0002_import_notion_glossary.py`）。
- ノード数が136から356に増える。地図が混み合わないよう、用語は思考法の外側の薄い殻に置き、詳細度4（近づいたときだけ名前が出る）とし、SETTINGS の NOTES で非表示にもできる。
- 検査に T-11（用語ノードの整合）を加える（DOC-05 v1.1）。
