## 指摘

### 中-1　英語の書名が単語の途中で折り返される（word-break: break-all が書誌にも効いている）
- 場所：templates/print.css `.srcs li { word-break: break-all; }`
- 内容：`break-all` が `li` 全体にかかっているため、URL だけでなく英語の書名・誌名も行末で語の途中から切れる。L0001a の付録Bで実際に「Public|ations」「An|nales」「Teles|copes」「Sup|ernova」が発生。URL も「…pnas.15.3.1|68」「ht|tps://…」のように1〜2文字だけ次の行に送られる箇所があり、行を節約する狙いに対して読みにくさの割に効果が小さい。設定自体は従来からあるが、URL を同じ行に置いたことで書名と URL が同じ行の中で折り返しを競うようになり、目立ちやすくなった（設定はそのままで、影響が増えた）。
- 修正案：折り返しの規則を書誌と URL で分ける。
  ```css
  .srcs li { margin-bottom: 0.7mm; overflow-wrap: anywhere; }   /* 書名は語の切れ目で折り返す */
  .srcs .url { font-family: var(--mono); font-size: 6.2pt; color: var(--muted); word-break: break-all; }
  ```
  あわせて詳細設計書 §4.1 の行に「長いURLは任意の位置で折り返す（URLのみ）」と書き足すと、設計と実装の対応が明確になる。修正後は L0001a・L0002 のページ数が変わらないか（増えても上限24以内か）を check_all で確認する。

### 中-2　CHANGELOG の「品質確認」が、このブランチに存在しないファイルと教材を根拠にしている
- 場所：CHANGELOG.md [0.5.1]
- 内容：「独立レビュー（content/cycles/0002/review.md）」は dev/compact-source-list には存在しない（サイクル2の作業は cycle/0002 側の stash にある）。また、そのレビューは教材の内容検証であり、本変更のコードレビュー（dev.md の Reviewer）ではない。変更理由の「L0002（出典100件超）」も、このブランチでは確認できない。dev.md の Tester 節が求める「check_all の結果を一行で残す」も入っていない。
- 修正案：品質確認を次のように改める。
  - 「独立レビュー（review_dev_0.5.1.md、またはその要約を置く場所）」
  - 「check_all: OK（L0000a 22→21p、L0001a 24→23p、他は変化なし）」
  - 変更理由の L0002 は「サイクル2で作成中の L0002 で…」のように、まだ main に入っていないことがわかる書き方にする。

### 低-1　URL（6.2pt・#7a7a7a）は読めるが、コントラストがぎりぎり
- 場所：templates/print.css `.srcs .url`（色は `--muted: #7a7a7a`、紙色 `#fbfaf7`）
- 内容：7pt の書誌は A4 で問題なく読める（110dpi の画像でも判読できた）。GoodNotes で iPad の画面幅に合わせると実効およそ 6pt 前後になるが、拡大すれば読め、出典一覧は「通読」ではなく「照合」に使う箇所なので許容範囲と判断する。ただし URL は 6.2pt の細い等幅で、灰色のコントラスト比が約 4.2:1 と、小さい文字の目安（4.5:1）をやや下回る。拡大しないと 0/O・l/1 の区別がつきにくい。
- 修正案：URL の色だけを `--ink2`（#3d3d3d）か #5e5e5e 程度に濃くする。紙幅には影響しない。

### 低-2　書誌の末尾と URL の区切りが半角スペース1つだけ
- 場所：tools/render_pdf.py `sources_html`
- 内容：「…2017 https://doi.org/…」のように、年と URL が空白1つで続く。書体と色の違いで区別はつくが、モノクロ印刷や拡大時に境目がわかりにくい。
- 修正案：`url = f"　<span class='url'>{s['url']}</span>"`（全角スペース）とするか、CSS で `.srcs .url { margin-left: 0.8em; }` を加える。

### 低-3（既存の問題）書名・URL を HTML エスケープしていない
- 場所：tools/render_pdf.py `sources_html`（`s['title']`、`meta`、`s['url']`）
- 内容：今回の変更で生じたものではないが、出典が100件を超えると、書名に `&` や `<`（例：「A & B」、数式の不等号）を含むものが出やすくなる。`&` は現状のブラウザでは表示が崩れないが、`<` があると以後の一覧が崩れる可能性がある。
- 修正案：`html.escape()` を title・meta・url に適用する（別の PATCH で可）。

## (1)〜(5) の確認結果
1. **設計書と実装の一致**：§4.1 の「7pt、行送り1.38、項目の間隔0.7mm、URLは同じ行に続ける（等幅6.2pt・灰色）」は CSS・render_pdf.py と一致。設計書の版（v3.2→v3.3）と変更履歴も更新済み。折り返しの規則は設計書に記載がない（中-1 の修正案参照）。
2. **可読性**：書誌 7pt は可。URL 6.2pt は照合用途として許容、色だけ濃くするとよい（低-1）。
3. **長い URL の折り返し**：はみ出し・重なりなどのレイアウト崩れはなし。ただし語の途中で切れる問題がある（中-1）。
4. **版・CHANGELOG**：system_version 0.5.0→0.5.1（PATCH）は表示の調整として妥当。graph.json の system_version も 0.5.1 に再生成済み。地図の版は変えておらず、変える必要もない。CHANGELOG の根拠の書き方に問題あり（中-2）。
5. **他の利用箇所への副作用**：`{{sources}}` を使うのは教材（lesson_a/b）だけで、report.md には出典一覧がない。R0001 の PDF の差分は生成時刻による1バイトのみ。L0000a は 22→21p、L0001a は 24→23p に減り、他は変わらない。CHANGELOG の「ページ数が減るのみ」は正しい。

## 総評
変更は小さく、設計書・実装・版の対応はとれており、check_all も通る。紙幅を詰める目的は達成している（L0001a で1ページ減）。マージの前に、**中-1（書名が語の途中で切れる）**と**中-2（CHANGELOG の根拠がこのブランチにない）**の2点を直すことを勧める。低の指摘は任意。
